# Changelog / История изменений

## 1.2.1 — 2026-10-14

### Русский

- Добавлена лаконичная монограмма **FTL**: тёмный бирюзовый на мягком лавандовом фоне.
- PNG 16/32/48/128 подключены к панели Chrome, карточке расширения и favicon popup. Векторный исходник и скрипт генерации включены в проект.
- Версия обновлена до 1.2.1. Подготовлен устанавливаемый ZIP и контрольная сумма SHA-256.
- Функции версии 1.2.0 сохранены: RU/EN по флагу, подмена часового пояса и языков, оба режима списков сайтов. Новые разрешения не требуются.

### English

- Added a minimal **FTL** monogram: dark teal on a soft lavender background.
- Registered 16/32/48/128 PNGs for the Chrome toolbar, extension card and popup favicon. Vector source and regeneration script are included.
- Bumped the version to 1.2.1, with an installable ZIP and SHA-256 checksum.
- Retained all 1.2.0 features: RU/EN flag controls, time zone and language overrides, and both website list modes. No additional permissions.

## 1.2.0 — 2026-10-14

- RU: Полный README RU/EN, мягкая палитра, переключение интерфейса флагами; подмена везде, кроме списка, или только на сайтах из списка. Домены включают поддомены; кнопка добавляет текущий сайт.
- EN: Complete RU/EN README, pastel interface, flag language controls; apply everywhere except a list or only on listed websites. Domain lists include subdomains; a button adds the current website.

## 1.1.0 — 2026-10-14

- RU: Название FakeTL / FakeTimeLanguage, английский и русский интерфейс с сохранением выбора.
- EN: FakeTL / FakeTimeLanguage branding and persistent English/Russian interface selection.
